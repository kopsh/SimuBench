# 验证场景：锁相放大器

状态：草案

第一个闭环的验证场景由“信号源 + 示波器定标”改为锁相放大器场景。场景参考 Galois Labs 的文章 [Lock-In Amplifier Simulation in Python](https://galoislabs.ai/blog/lock-in-amplifier-simulation)（EdgeSim 0.2.0）。原理参考 Stanford Research Systems 的应用笔记 [About Lock-In Amplifiers](https://www.thinksrs.com/downloads/pdfs/applicationnotes/AboutLIAs.pdf)。

## 为什么选这个场景

1. **天然适合模块化（D1）**：锁相放大器本身就是一条清晰的信号链，Liquid Instruments 的 Moku 也把锁相放大器作为软件定义仪器之一：

   ```
   SIG_IN → 耦合（DC / AC 0.16 Hz 高通）→ 前端噪声 → 过载检测
                                                    ↓
   参考（内部振荡器 / REF_IN 锁相 / 谐波 n）→ 乘法器 ×cos、×sin
                                                    ↓
                               n 阶低通（时间常数 T、斜率 6–24 dB/oct）
                                                    ↓
                                     X、Y → R、θ → 输出过载检测
   ```

2. **有已知真值**：被测对象是 RC 低通（1 kΩ、100 nF，转折频率 1591.55 Hz），理想传递函数已知，测量结果可以逐点和理论值比对。
3. **覆盖关键行为**：虚拟时间下的建立过程、按随机种子确定的噪声、外部参考与连线、量程梯级、自动功能、过载与错误队列、模型能力边界。
4. **有公开的参考结果**：EdgeSim 文章给出了每个脚本的输出，可以作为验收数据，客观判断 SimuBench 的结果是否正确。

## 锁相放大器模型能力

| 设置 | 范围 |
| --- | --- |
| 参考 | 内部 1 mHz–500 kHz，或外部 REF_IN；谐波 n = 1–99，n × f ≤ 500 kHz |
| 灵敏度 | 2 nV–1 V，1-2-5 梯级，共 27 档 |
| 时间常数 | 10 µs–30 ks，1-3 梯级，共 20 档 |
| 斜率 | 6 / 12 / 18 / 24 dB/oct（1–4 阶） |
| 耦合 | DC，或 AC（0.16 Hz 高通） |
| 输出 | X、Y、R、θ；SNAP? 同一时刻读取最多 4 个量 |
| 自动功能与标志 | 自动相位、自动增益；过载位 1（输入）与 2（输出） |
| 错误码 | 325 输入过载、326 输出过载、327 参考失锁、328 时基失锁、329 超出模型能力、-221 设置冲突 |

写入不在梯级上的值时，按对数刻度取最近一档（如灵敏度 0.3 V 存为 0.2 V）。

## 验收标准

以下数值来自 EdgeSim 文章的公开输出。SimuBench 在同样的 Bench 和操作下应得到一致的结果，允许的偏差待定。

### 1. 建立过程

- 4 阶、T = 30 ms：ENBW = 2.6042 Hz，建立到 99% 的时间为 0.3014 s。
- 建立到 99% 所需的时间常数倍数：6 / 12 / 18 / 24 dB/oct 分别为 4.605 / 6.638 / 8.406 / 10.045。
- 0.5 Vrms 驱动、转折频率处，R 的终值为 353.478 mV；建立曲线符合 n 阶指数公式，偏差约 0.04 mV（来自 2f 纹波）。
- 未等待就读数时，读到的是滤波器的中间值，而不是信号的终值。

### 2. Bode 扫描

- 转折频率处：−3.01 dB、−45.00°；高于转折频率时约 −20 dB/十倍频，相位趋近 −90°。
- 每点等待 1 倍建立时间：R 最大误差 1.0e-2，θ 最大误差 0.252°；等待 2 倍：R 最大误差 2.8e-6。
- 1 Vrms 驱动时峰值 1.41 V，超过 1.4 V 前端限值，错误队列出现 325。

### 3. 噪声

- 前端白噪声默认 5 nV/√Hz；每个正交分量 σ = eₙ · √ENBW。
- n 阶 ENBW = C(2n−2, n−1) / (4ⁿ · T)，即 1/(4T)、1/(8T)、3/(32T)、5/(64T)。
- 噪声由随机种子和虚拟时间确定：同一时刻两次读数相同，一个时间常数以内的读数相关。

### 4. 外部参考与谐波

- 1 V 峰值方波，n = 1 / 3 / 5 时 R = 900.31 / 300.10 / 180.06 mV（4/(πn)/√2）。
- n × f > 500 kHz 时写入被拒，错误码 −221。
- 参考信号停止：`:REFerence:LOCKed?` 返回 0，产生一次 327，振荡器保持最后的频率；参考恢复后重新锁定。

### 5. 量程、耦合与自动功能

- 灵敏度 0.2 V 时只有输出过载（位 2，错误 326）；10 mV 时输入、输出都过载（位 3，错误 325）。
- 自动增益选择让 R 低于满量程 90% 的最小档位（R = 353 mV 时选 0.5 V）；时间常数大于 1 s 时拒绝执行，错误码 −221。
- 自动相位设置的是终值相位，θ 需要经过建立时间后才到 0°。
- 0.5 V 直流背景上叠加 0.707 mVrms 信号、灵敏度 2 mV：DC 耦合输入过载（325），AC 耦合不过载；两种情况下 R 都是 0.7071 mV。

### 6. 模型能力边界

- 方波输入在宽滤波器（6 dB/oct、100 µs，ENBW 2500 Hz）下产生 329；窄滤波器下不产生。
- 16 点任意波在参考频率上：R = 698.07 µV，无错误；在 1001 Hz：产生 329，读数为窗口平均值。

## 与参考实现的数值差异（D13：物理正确优先）

参考实现按 1 kΩ 计算 RC 转折频率（1591.55 Hz），另把 50 Ω 输出阻抗计入直流分压。SimuBench 把 SINE_OUT 的 50 Ω、RC 与两个 10 MΩ 输入作为一个电路求解：50 Ω 与 1 kΩ 串联，转折频率为 1/(2π × 1050 Ω × 100 nF) = 1515.76 Hz。

受影响的验收值按电路理论重新计算（0.5 Vrms 开路驱动）：

| 频率 | R | 增益 | θ |
| --- | --- | --- | --- |
| 100 Hz | 498.811 mV | −0.02 dB | −3.77° |
| 200 Hz | 495.601 mV | −0.08 dB | −7.52° |
| 500 Hz | 474.743 mV | −0.45 dB | −18.25° |
| 1 kHz | 417.295 mV | −1.57 dB | −33.41° |
| 1515.8 Hz（新转折频率） | 353.512 mV | −3.01 dB | −44.99° |
| 1591.55 Hz（原转折频率） | 344.793 mV | −3.23 dB | −46.39° |
| 3 kHz | 225.471 mV | −6.92 dB | −63.19° |
| 6 kHz | 122.464 mV | −12.22 dB | −75.82° |
| 10 kHz | 74.932 mV | −16.49 dB | −81.38° |
| 20 kHz | 37.786 mV | −22.43 dB | −85.67° |

- 不受影响的验收项：建立过程的公式与倍数、ENBW、噪声、谐波检测（方波直接接 SIG_IN）、量程与过载规则、错误码、模型能力边界。
- 建立过程与自动功能中用到“转折频率处”数值的条目（如 R 终值 353.478 mV、自动增益选择 0.5 V），按 1591.55 Hz 处的新值 344.793 mV 重新核对，或把测试频率改为 1515.76 Hz。

### 实现后的其他差异（M3）

- **任意波在 1001 Hz**：参考实现对任意波做数值解调，偏离参考频率 1 Hz 时窗口无法平均，产生 329、读数为窗口平均值。SimuBench 的任意波由表格的精确谱线表示（线性插值的谱为 X[k]/N · sinc²(k/N)，参考频率上 698.07 µV 与参考实现一致），解调同样精确，因此 1001 Hz 不是模型的能力边界：不产生 329，R 是滤波器真实的（拍频）输出（D30）。
- **329 的判定**：截断的输入（方波、锯齿的谐波上限，任意波的谐波上限）在第一条被舍去的谱线处，若滤波器增益超过 1e-6 则产生 329；宽滤波器（6 dB/oct、100 µs）产生，窄滤波器（24 dB/oct、30 ms）不产生，与参考实现一致。
- **噪声的具体取值**：同一种子下的噪声序列与参考实现不同（各自的随机数发生器），统计性质一致：400 次读数的标准差在预测值的 ±12% 内（验收测试）。
- **建立曲线**：按 n 阶指数的闭式解精确计算；读数与公式之差小于 0.05 mV（参考实现约 0.04 mV）。

## 模拟不证明的内容

与 EdgeSim 相同，明确写入能力边界：

- 前端的 1/f 噪声与漂移；
- 真实锁相环的捕获时间与跟踪；
- 锁相放大器之前的信号路径（光电二极管、前置放大器等需要作为 DUT 模型声明）；
- 真实通信与处理延迟。

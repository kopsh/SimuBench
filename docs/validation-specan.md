# 验证场景：频谱分析仪

状态：草案

第一个闭环的第四个验证场景。参考 Galois Labs 的文章 [Simulate a Spectrum Analyzer for Test Automation](https://galoislabs.ai/blog/spectrum-analyzer-simulation)（EdgeSim 0.2.0、PyVISA 1.16.2、Python 3.13）。

## 为什么选这个场景

1. **与射频信号源场景共用频谱仪模型**：同一个仪表模型在两个 Bench 中使用，验证仪表模型的复用。
2. **覆盖噪声与统计**：接收机热噪声底、四种检波器、三种迹线模式、平均与最大保持，结果可与理论公式比对。
3. **覆盖设置之间的耦合**：RBW、VBW、扫描时间、衰减的自动规则，以及手动设置如何解除耦合。
4. **覆盖虚拟时间对测量的影响**：平均和最大保持需要扫描，扫描需要虚拟时间；没给时间的迹线只是第一次扫描。
5. **覆盖用户自定义仪表**：用一个很小的定义文件加入 PRBS 信号源，并走数值（FFT）计算路径。

## 测试台

| 仪表 | 连接 | 初始状态 |
| --- | --- | --- |
| 函数发生器 1 | OUT1 → 频谱仪 RF_IN | 100 kHz 方波、1 Vpp、输出开启 |
| 函数发生器 2 | OUT1 → 频谱仪 REF_IN | 10 MHz + 20 Hz 正弦（快 2 ppm）、输出开启 |
| 频谱仪 | — | 0–1 MHz（中心 500 kHz、跨度 1 MHz）、参考电平 +10 dBm、锁定外部参考 |

另有一个 PRBS Bench：用户自定义的 7 阶 PRBS 信号源（比特率与电平可设）→ 频谱仪 RF_IN，定义文件放在 Bench 旁边的目录中。

网络上的信号：方波为频率 100 kHz、幅度 0.25 V（1 Vpp 开路即 0.5 V 峰值，50 Ω 输入分压一半）。n 次谐波峰值 4A/(πn)，功率 V²/2R。

## 频谱仪模型能力

| RF_IN 上的信号 | 计算方式 |
| --- | --- |
| 正弦及其嵌套组合 | 每个分量一条谱线，功率 V²/2R（50 Ω） |
| 方波、锯齿 | 精确傅里叶级数，每个谐波一条谱线 |
| 任意波、PRBS、削波信号 | 加窗 FFT，记录长度由 RBW 决定 |
| 噪声项 | 白噪声，带宽由隐藏的接收机设置决定（默认 7.5 GHz） |
| 接收机本身 | kT₀·F·NBW：−174 dBm/Hz + 噪声系数 24 dB + 衰减，噪声带宽 1.0645 × RBW |

- RBW 滤波器为高斯型，1-3-10 梯级，1 Hz–3 MHz；频率范围 0–7.5 GHz。
- 迹线是设置、RF_IN 历史信号、种子和扫描计数的纯函数：同一虚拟时刻两次读取逐字节相同。
- 理想接收机：无电平误差与平坦度波动、无压缩、无零跨度、无跟踪源、无测量应用。

设置耦合规则：

| 设置 | 自动规则 | 手动设置 |
| --- | --- | --- |
| RBW | 跨度 / 100，取 1-3-10 梯级 | 取最近一档，自动关闭 |
| VBW | 等于 RBW | 取最近一档，自动关闭 |
| 扫描时间 | 2.5 × 跨度 / (RBW × min(RBW, VBW))，至少 1 ms | 按给定值，自动关闭 |
| 衰减 | 使参考电平在混频器处为 −10 dBm，2 dB 步进 | 按给定值，自动关闭 |

## 验收标准

以下数值来自 EdgeSim 文章的公开输出。SimuBench 在同样的 Bench 和操作下应得到一致的结果，允许的偏差待定。

### 1. 连接与网络

- Bench 校验通过、退出码 0；两个网络分别为方波（100 kHz、0.25 V、占空比 0.5）与正弦（10 000 020 Hz、0.25 V），驱动源正确。
- PyVISA 地址 5025、5026、5027；两台函数发生器 `*IDN?` 相同，按型号找到频谱仪；峰值搜索得到 100 kHz、+0.057 dBm。

### 2. 设置耦合

| 操作 | RBW | VBW | 扫描时间 | 衰减 | 过载 |
| --- | --- | --- | --- | --- | --- |
| 初始（跨度 1 MHz） | 10 kHz（自动） | 10 kHz（自动） | 0.025 s | 20 dB | 0 |
| 跨度 10 MHz、中心 5 MHz | 100 kHz | 100 kHz | 2.5 ms | 20 dB | 0 |
| RBW 设 2 kHz | 3 kHz（手动） | 3 kHz（自动） | 2.778 s | 20 dB | 0 |
| 扫描时间设 50 ms | 3 kHz | 3 kHz | 0.05 s，UNCal = 1 | 20 dB | 0 |
| 恢复自动、参考电平 −20 dBm | 100 kHz | 100 kHz | 2.5 ms | 0 dB | 1 |
| 参考电平 +10 dBm | 100 kHz | 100 kHz | 2.5 ms | 20 dB | 0 |

- 跨度 1 MHz 时把中心设为 200 kHz 会使起点为负：窗口滑动，中心仍为 500 kHz，不产生错误。
- 过载时读数不压缩；方波总功率 +0.97 dBm，超过混频器 −10 dBm 的限值。

### 3. 迹线与标记

- `:TRACe:DATA? TRACE1` 返回 1001 点、0–1 MHz，最高点 +0.057 dBm（100 kHz）。
- 峰值阈值 −30 dBm、峰值偏移 6 dB，依次读取奇次谐波：

  | n | 标记频率 | 计数器频率 | 电平 |
  | --- | --- | --- | --- |
  | 1 | 100 000 Hz | 99 999.8 Hz | +0.0570 dBm |
  | 3 | 300 000 Hz | 299 999.4 Hz | −9.4854 dBm |
  | 5 | 500 000 Hz | 499 999.0 Hz | −13.9224 dBm |
  | 7 | 700 000 Hz | 699 998.6 Hz | −16.8450 dBm |
  | 9 | 900 000 Hz | 899 998.2 Hz | −19.0279 dBm |

- 计数器读数除以 1.000002：频谱仪锁定在快 2 ppm 的外部参考上，继承了它的误差。
- 第 9 次谐波之后再搜索下一个峰值：−200，标记不动。

### 4. 检波器与噪声底

跨度 100 kHz、中心 200 kHz、101 点、RBW 100 Hz、衰减 20 dB；理论噪声底 kT₀·F·NBW = −109.73 dBm：

| 检波器 | 噪声底均值 | 离散度 | 与理论之差 | 300 kHz 谱线 |
| --- | --- | --- | --- | --- |
| SAMPle | −112.07 dBm | 5.58 dB | −2.35 dB | −9.4859 dBm |
| POSitive | −103.85 dBm | 1.36 dB | +5.87 dB | −9.4854 dBm |
| AVERage | −110.85 dBm | 0.77 dB | −1.12 dB | −9.4859 dBm |
| RMS | −109.77 dBm | 0.87 dB | −0.05 dB | −9.4859 dBm |

- 对数平均使 SAMPle 与 AVERage 偏低（模型说明：低于功率 2.51 dB）。
- RMS 检波、RBW 1 kHz、1001 点，衰减 0 / 10 / 20 / 30 dB：噪声底 −119.74 / −110.10 / −99.46 / −89.75 dBm，理论 −119.73 / −109.73 / −99.73 / −89.73 dBm。
- QPEak 检波器被拒绝，−224。

### 5. 迹线模式与虚拟时间

- 同一虚拟时刻两次读取的迹线完全相同。
- 噪声底、SAMPle 检波、RBW 1 kHz（扫描时间 0.25 s）、平均次数 10，推进 10.5 次扫描时间：

  | 模式 | 均值 | 离散度 |
  | --- | --- | --- |
  | WRITe | −102.09 dBm | 5.49 dB |
  | AVERage | −102.34 dBm | 1.75 dB（≈ 5.49 / √10） |
  | MAXHold | −95.37 dBm | 1.77 dB |

- 信号源在 100 kHz 停留 20 次扫描后移到 150 kHz 再停留 20 次（POSitive 检波、平均次数 40、扫描时间 0.025 s）：

  | 模式 | 100 kHz | 150 kHz |
  | --- | --- | --- |
  | WRITe | −100.08 dBm | +0.06 dBm |
  | AVERage | −43.01 dBm | −47.81 dBm |
  | MAXHold | +0.06 dBm | +0.06 dBm |

- `:TRACe:CLEar` 后不推进时间：100 kHz −89.82 dBm，150 kHz +0.06 dBm。
- 更改迹线模式会重新开始累计。

### 6. FFT 路径（PRBS）

- 7 阶 PRBS、比特率 100 kb/s、网络幅度 0.125 V；跨度 20 kHz、中心 10 kHz、RBW 100 Hz：1001 点，扫描时间 5 s。
- 谱线 k 位于 k × R / 127，峰值 2A·√128 / 127 · |sinc(k/127)|；k = 1, 2, 5, 12, 20, 25 处与闭式解相差 −0.014 / +0.015 / −0.016 / −0.015 / −0.009 / −0.037 dB（主要来自标记落在最近的 20 Hz 频点）。
- FFT 估计没有镜像抑制，0 Hz 附近三个 RBW 以内的谱线读数偏高（模型说明）。

### 7. 能力上限与错误

- 100 Hz 方波、跨度 20 MHz：谱线过多，保留最强的谱线（最高 +0.97 dBm），每次读取迹线都产生 −221（太多谱线，最弱的被丢弃）。
- 10 Mb/s PRBS、RBW 1 Hz：需要超过 2²⁰ 点的 FFT 记录，迹线只有噪声底（最高 −130.07 dBm），产生 −221；改为 RBW 1 kHz 后谱线 −23.04 dBm，无错误。
- 其他上限：窗口内超过 65 536 条谱线或 2×10⁷ 个谱线-频点对；最大保持超过扫描次数上限（1001 点时 999 次）时保留最新的扫描，每次重新开始累计时报告一次。

| 操作 | 结果 |
| --- | --- |
| 跨度 1 Hz | −222 |
| 中心 8 GHz | −222 |
| RBW 0.5 Hz | −222 |
| 检波器 QPEak | −224 |
| 无信号时峰值搜索 | −200 |
| 无参考时选择外部参考 | 失锁、使用 INT、−221（附说明） |

- −221 在每次 `:TRACe:DATA?` 时重复产生，直到设置改变；不使用 −241。

## 对 SimuBench 的启示

1. **PyVISA 会话无法推进虚拟时间**：EdgeSim 在需要迹线模式时改用进程内 API 调用 `advance()`，脚本因此与真机脚本不同。SimuBench 需要让未修改的脚本也能获得虚拟时间（已由 D12 解决：命令驱动的虚拟时间）。
2. **噪声必须确定**：噪声由种子与扫描计数决定，统计特性（√N、检波器偏差）又必须正确，两者同时满足。
3. **设置耦合本身就是被测对象**：脚本常常自己计算扫描时间或 RBW，模型的耦合规则必须与真实仪表一致并公开。
4. **自定义仪表进入闭环**：一个十几行的定义文件即可加入新的信号源，验证声明式定义（D3 第 3 层）与 Bench 旁的定义目录。

# 验证场景：射频信号源调制

状态：草案

第一个闭环的第三个验证场景。参考 Galois Labs 的文章 [RF Signal Generator Simulation: AM, FM and PM](https://galoislabs.ai/blog/rf-signal-generator-modulation)（EdgeSim 0.2.0、Python 3.13）。

## 为什么选这个场景

1. **覆盖射频与频域**：载波、调制边带、频谱分析仪的标记与峰值搜索，与锁相放大器（谱线解调）、示波器（时域采样）形成互补。
2. **覆盖时基与参考连线**：信号源 REF_OUT 接频谱仪 REF_IN，时基误差在两台仪表之间传递；同一个测量在锁定与未锁定参考时结果不同。
3. **覆盖“隐藏状态”**：信号源时基快 2 ppm，没有任何命令能读出，只能通过测量发现。这与定标场景中“DUT 的真实误差已知、但仪表不会直接报告”是同一个概念。
4. **覆盖模型能力边界与拒绝**：卡森规则截断、谱线数上限、不支持的脉冲调制，都以明确的错误码拒绝，而不是返回看似合理的错误结果。
5. **再次覆盖阻抗**：电平按匹配 50 Ω 负载定义；接高阻输入时读数比设置值高 6.02 dB。

## 测试台

| 连线 | 说明 |
| --- | --- |
| 信号源 RF_OUT → 频谱仪 RF_IN | 射频信号 |
| 信号源 REF_OUT → 频谱仪 REF_IN | 10 MHz 参考，+4 dBm |

初始状态：

- 信号源：1 GHz、0 dBm、输出开启；隐藏状态 `timebase.offset_ppm = 2.0`；
- 频谱仪：中心 1 GHz、跨度 5 MHz、参考电平 +10 dBm；1001 点（间隔 5 kHz）、自动 RBW 30 kHz、自动衰减 20 dB。

## 信号源模型能力

| 功能 | 范围或规则 |
| --- | --- |
| 载波 | 9 kHz–6 GHz |
| 电平 | −130 至 +20 dBm（匹配 50 Ω 负载） |
| AM | 深度 0–100%，内部调制频率 0.1 Hz–1 MHz；精确 |
| FM | 频偏 0–10 MHz，调制频率 0.1 Hz–1 MHz；贝塞尔谱线，按卡森规则截断 |
| PM | 相偏 0–100 rad，调制频率 0.1 Hz–1 MHz；贝塞尔谱线，按卡森规则截断 |
| 扫描 | 步进扫描（起止、点数、线性/对数）与列表扫描（最多 1601 点），由命令逐点触发 |
| 时基 | 10 MHz，内部或锁定 REF_IN（10 ppm 以内）；REF_OUT 携带自身时基误差 |
| 脉冲调制 | 拒绝，−221 |

信号源是理想的：电平精确，无相位噪声、杂散、谐波，无建立时间。

## 验收标准

以下数值来自 EdgeSim 文章的公开输出。SimuBench 在同样的 Bench 和操作下应得到一致的结果，允许的偏差待定。

### 1. 调制边带

频谱仪锁定到 REF_OUT，峰值阈值 −60 dBm（噪声底约 −85 dBm），用峰值搜索与“下一个峰值”逐个读取：

| 调制 | 偏移 | 电平（dBc） |
| --- | --- | --- |
| AM 30%、1 MHz | ±1 MHz | −16.478 |
| | 0 | 0.000 |
| FM 频偏 1 MHz、1 MHz（β = 1） | ±2 MHz | −18.793 |
| | ±1 MHz | −7.130 |
| | 0 | −2.325 |
| PM 相偏 1 rad、1 MHz（β = 1） | 同 FM | 同 FM |

测量值与闭式解在显示位数内完全一致；两次读取间仪表均无错误。

### 2. 参考电平与过载

- AM 30% 使总功率增加 m²/2（0 dBm 载波变为 +0.19 dBm）。
- 参考电平 0 dBm 时自动衰减 10 dB，第一混频器处 −9.81 dBm，超过 −10 dBm 的限值：无调制时过载标志为 0，AM 30% 时为 1，FM β = 5（包络恒定）时为 0。
- 参考电平 +10 dBm 时衰减 20 dB，过载标志保持 0。

### 3. 卡森规则截断

- 每侧保留阶数 floor(β) + 1：

  | β | 每侧阶数 | 遗漏功率 | 遗漏 dB |
  | --- | --- | --- | --- |
  | 0.50 | 1 | 0.00189 | −27.24 |
  | 1.00 | 2 | 0.00078 | −31.09 |
  | 2.00 | 3 | 0.00241 | −26.17 |
  | 5.99 | 6 | 0.04035 | −13.94 |
  | 6.00 | 7 | 0.00739 | −21.31 |
  | 10.00 | 11 | 0.01004 | −19.98 |

- 任意 β 下遗漏功率不超过载波功率的 0.0410（−13.9 dB）。
- β = 1 时只有 5 条谱线：第 6 次峰值搜索失败并产生 −200；精确解中 J₃(1) 应在 −34.2 dBc。
- β = 2.404826（J₀ 的零点）时载波消失，载波处读数约 −85.1 dBm（噪声底）。
- 谱线数上限 999 条；β = 10⁸（频偏 10 MHz、调制频率 0.1 Hz）被拒绝，−222，FM 保持关闭。

### 4. 列表与步进扫描

- 频谱仪覆盖 0–7.5 GHz，自动 RBW 3 MHz，1001 点。
- 不带引号的列表 `1e9,2.4e9,5.8e9` 被拒绝（−108）；带引号的列表被接受，共 3 点。
- 列表扫描、频谱仪使用内部时基（信号源快 2 ppm）：1.000002000 GHz、2.400004800 GHz、5.800011600 GHz，电平均为 0.00 dBm；超过最后一点后停留在第 3 点。
- 步进扫描 1–2 GHz、5 点线性、频谱仪锁定 REF_OUT：1.00、1.25、1.50、1.75、2.00 GHz，频率完全准确。

### 5. 时基与参考

- 网络上的信号：RF_OUT 为 1 000 002 000.0 Hz、0.3162 V 峰值；REF_OUT 为 10 000 020.0 Hz、0.5012 V 峰值（+4 dBm）。
- 频谱仪内部时基：载波读数 1 000 002 000.0 Hz，未锁定。
- 锁定 REF_OUT：读数 1 000 000 000.0 Hz，锁定，使用 EXT。
- 关闭 REF_OUT：读数回到 1 000 002 000.0 Hz，失锁，回到 INT，并产生 −221（附说明：REF_IN 需要 10 ppm 以内的 10 MHz 正弦）。

### 6. 拒绝与错误码

| 操作 | 结果 | 之后的状态 |
| --- | --- | --- |
| 打开脉冲调制 | −221（脉冲调制不仿真） | PULM 0 |
| FM 开启时再打开 PM | −221 | 后打开的 PM 生效，FM 关闭 |
| 电平 +25 dBm / −131 dBm | −222 | 不变 |
| 载波 7 GHz / 8 kHz | −222 | 不变 |
| FM β = 10⁸ | −222 | FM 关闭 |

- AM 可与 FM 或 PM 叠加；FM 与 PM 互斥。
- 错误码只使用 −221、−222、−224，不使用会被主机当作断线的 −241。
- 通过 Bench 文件或界面写入的非法状态同样受这些规则约束：下一次求解时被修正，并产生一次错误。

## 模拟不证明的内容

| 模拟能证明 | 需要真实信号源与测试台 |
| --- | --- |
| 哪些命令设置哪种调制、顺序是否正确 | 调制精度、失真、边带不对称 |
| 脚本是否从正确的谱线、以正确的单位读出边带电平 | 相位噪声、杂散、谐波、稳幅误差 |
| 列表与步进扫描逻辑 | 真实扫描的切换时间与驻留 |
| 脚本是否检查参考锁定与错误队列 | 真实参考是否接好、是否足够好 |
| 脚本能否处理被拒绝的设置 | 脉冲调制本身 |

另外，多谱线信号在万用表或示波器上按 1 ms 窗口测量，只有窗口包含整数个调制周期时有效值才精确（调制频率为 1 kHz 的整数倍）。这是测量窗口的限制，不是信号源的限制，需要写入模型说明。

## 对 SimuBench 的启示

1. **隐藏状态就是真值**：信号源的时基偏差、锁相放大器的前端噪声密度、定标场景中 DUT 的真实误差，是同一个概念：Bench 可以设置、命令读不到、只能通过测量发现。SimuBench 应把它作为 Bench 定义中的一等概念，并与 MCP 的真实值可见性开关（D9）统一。
2. **参考与时基是跨仪表的连线**：时基误差沿 REF_OUT → REF_IN 传递，说明连线不只传递“信号”，也传递“时钟”。
3. **信号描述需要预算与截断规则**：无穷谱线必须按明确规则截断（卡森规则、谱线上限），并公开误差界。
4. **拒绝比“看似合理的错误结果”更重要**：不支持的功能必须以错误码拒绝，并保持状态不变。
5. **与真实仪表的偏差要单独标注**：例如列表参数必须加引号（真实仪表接受不加引号的形式）。这类偏差来自 EdgeSim 模型格式的限制，不是物理行为。

# 界面设计

状态：生效（D22、D23、D24）。本文定义 Web Bench 的界面参考、布局、视觉语言与交互规范；实现以设计令牌与组件库为准。

## 1. 参考软件与借鉴点

跨领域选取在“专业用户、高信息密度、长时间使用”上做得好的软件，按要解决的问题借鉴：

| 要解决的问题 | 参考 | 借鉴点 |
| --- | --- | --- |
| 多台仪表的组合与信号路由 | Liquid Instruments Moku（多仪器模式）、NI InstrumentStudio | 仪表以卡片/面板呈现，路由关系可视化；仪表面板与连接关系同屏 |
| 现代仪表软件的观感与波形 | Saleae Logic 2、Keysight PathWave BenchVue | 深色为主的测量界面；时间轴缩放平移顺滑；测量值与波形并列；克制的配色 |

| 电路与拓扑 | KiCad、LTspice、Simulink | 端口方向与介质明确；网络高亮；在连线上标注配件；模块可“打开”查看内部 |
| 工作台布局 | VS Code、JetBrains IDE | 左侧资源管理、中央编辑区、右侧检查器、底部面板（问题、输出、终端）；命令面板；全部可用键盘完成 |

| 时间线与回放 | Chrome DevTools 性能面板、Rerun、Foxglove Studio | 统一时间线上叠放命令、状态变化、事件；拖动时间游标回看任意时刻；面板布局可保存 |

```
SimuBench
├─ 首页：产品介绍（Hello World 实时预览、网页/终端/脚本三种界面、仪表库，D65）；有测试台时先列出我的测试台、打开中的测试台与运行记录

│   ├─ 画布（仪表、DUT、连线与配件）

```

## 3. 工作台布局

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ◧ SimuBench  测试台：示波器-RC ▾   ● 运行中  ▶ ⏸ ⏭ 1×   t = 00:00:04.200   ⌘K │  顶栏
├──────┬──────────────────────────────────────────────────────┬───────────────┤
│ 资源 │                                                      │ 检查器        │
│ ──── │                  画布 / 仪表屏幕（标签页）            │ ───────────── │
│ 仪表 │                                                      │ 示波器 CH1    │
│ DUT  │   ┌ 函数发生器 ┐       ┌ RC ┐        ┌ 示波器 ──────┐ │ 档位 50 mV/div│
│ 连线 │   │ CH1 1 kHz  │──────▶│    │──10×──▶│  ∿∿∿         │ │ 耦合 DC       │
│ 网络 │   └────────────┘       └────┘        └──────────────┘ │ 真实值 ⓘ     │
│      │                                                      │               │
├──────┴──────────────────────────────────────────────────────┴───────────────┤
│ 通信 │ 事件 │ 问题 2 │ 时间线 │ 运行记录                                      │  底部面板
│ 00:00:04.200  scope  :WAVeform:DATA?  → #42000…  2007 B                       │
└─────────────────────────────────────────────────────────────────────────────┘
```

- **顶栏**：测试台名称与切换、运行状态、时钟控制（运行、暂停、单步、倍速）、虚拟时间、命令面板入口。
- **左侧资源栏**：测试台内的仪表、DUT、连线、网络的树形列表，与画布双向选中。空的分组不显示；网络以它连接的仪表与元件端口命名（如 `rc.OUT · scope.CH1`），连线附件内部的点（探头两端）不列出，完整成员与网络 id 在悬停提示里（#1222）。
- **中央**：画布与仪表屏幕以标签页并存；画布可与一个仪表屏幕左右分屏。画布的小地图只在有节点落在视口外时出现，测试台放得下时不画，免得底栏展开、画布变矮后盖住右下角的节点（#1252）。出现时它占第一个不压住节点的角（右下、右上、左上；左下是缩放按钮），三个角都会压住节点时不画（#1269）。搭建时把一个输出拖向会让同一网络出现两个驱动源的端口（两个输出相连，或输出接到已有驱动源的网络），松手前画布顶部就写出原因和两端的端口名，松手不连；服务端同样拒绝这样的 `connect`，文件不改。确有这种连线的文件（手写或旧文件），问题指向网络里最新加的那条线，原来正确的线照常画出；因错误未画出的连线用两端写出（`scope.CAL_OUT → awg.CH1`），不用内部编号。函数发生器屏幕在每个通道的设置下面画出按设定值算出的两个周期输出波形（函数、幅度、偏置、占空比、对称度；任意波、噪声只写函数名），填满屏幕高度（#1252）。
- **右侧检查器**：选中对象的参数（可编辑）、状态、隐藏状态与真实值（受开关控制）、诊断。按标签页的种类显示或收起（#1221）：画布与仪表屏幕旁显示；在一台仪表自己的屏幕旁，屏幕上已有输入框的设置不在检查器里重复（#1229：同一个值只有一处可改），只留身份与地址、屏幕上没有的设置、SCPI 控制台与故障注入，并注明“另有 N 项设置在屏幕上修改”，宽度也默认窄一些（18%，画布旁 24%），让给屏幕；哪些设置在屏幕上不按类别列清单，由屏幕里渲染的设置输入框登记（`onScreen.ts`），定义自带面板与通用布局也一样适用；不经设置输入框、直接发 SCPI 的屏幕字段（频谱仪的中心频率、跨度；RBW 与扫描时间的屏幕字段读的是生效值，检查器仍保留其手动设定与自动开关）也按设置路径登记（#1252）。仪表检查器顶部一个主按钮“打开屏幕”，下面一排三个次要按钮（内部结构、验收、存为模板，完整名称在提示与无障碍名称里，#1252）。脚本连接着仪表（远程，#121）时只有一份完整提示和一个“本地（LOCAL）”按钮（#1273）：仪表屏幕顶部是完整横幅（说明、客户端、按钮在右）；屏幕旁的检查器只在标题右侧放一个小标记（锁形图标 +“远程”，或“本地”），悬停列出客户端；不在该仪表屏幕旁时，检查器顶部是窄栏横幅：标题行带按钮，下面一行短说明与客户端地址（完整、可折行、可整段选中）横向排满栏宽，完整说明在悬停提示里，高度不超过约 80 px，不把正文挤到按钮旁的一窄列。SCPI 控制台的示例用每台仪表都答的 `*IDN?` 与 `:SYSTem:ERRor?`，而不是 #1252 验收写的“该仪表定义里第一条可查询命令”：定义里的第一条可查询命令常是一条冷僻的状态或文件命令（UXR 的 `:ACQuire:ADC:CLIPped`），不是用户第一次在控制台里想发的，且换一台仪表示例就变；两条公共命令每台仪表都答，答了也说明连接与错误队列都通（#1267 记下这一取舍）。别名选项（UXR 的 `DCFifty` 与 `DC50` 同为“DC 50 Ω”）只列一次，除非它就是当前值。示波器屏幕用旋钮与读数而不是设置输入框，它旁边的检查器照旧完整。检查器宽度按标签页种类记在本浏览器，拖动边缘只改当前种类；内部结构与验收页有自己的侧栏，默认收起，把宽度让给页面。标签栏末端的按钮切换，选择按种类记在本浏览器；收起时用户选中对象（屏幕上点信号源、资源树里点仪表）或“在检查器中定位”会临时展开，换标签页后恢复。底部面板的“通信”“事件”标签带条数，收起时也能看到里面有什么；没有通信、事件与问题时底栏只有一行高（标签栏），有内容时第一次自动展开。内部结构与验收页是当前标签页时底栏收起为标签栏，把高度让给图；回到画布或屏幕时恢复展开；在这两页上手动展开的，到下一次切换前保持（#1258）。仪表的设置分层显示（#728）：定义的 `display.summary` 与所选通道的 `channel_summary` 在最前，有名字的不带路径前缀的设置紧随；其余按路径首段分组。分组默认展开的条件是：不是远程编程组（通信、波形传输、状态、系统、数据格式等），且多数设置有 `label`（定义作者当作旋钮的，如万用表的孔径、源表的自动量程）；没名字的设置（如示波器模板里没标注的测量槽与通信设置）与远程组默认折叠，没名字的不带前缀的设置归入“其他”。显示超过 12 行（测量槽、实例族各算一行）的分组也默认折叠：点一次仪表只挂载首屏要看的设置，UXR 示波器原先一次展开约 600 个字段，单击要 3~5 秒（#1299）。同一前缀的编号分组至少 4 个时（`function1`…`function16`）合并为一组（“数学函数”），默认折叠，组内用编号选择器一次显示一个，与实例族相同。下拉框关闭时只渲染当前值那一项，打开时才渲染全部选项（`components/ui/select.tsx`）；会话每隔几秒轮询时只取设置的值（`GET /api/sessions/{sid}?state=values`），定义（选项、名称、范围）只在会话的 `build` 变化时（启动、重置、重建）整取一次（#1299）。多通道仪表一次显示一个通道，用 CH 选择器（通道色）切换，不再上下堆叠；选择器不跟随画布的选中（#733）：工作台的 selection 只有对象与 id、不带通道号，画布上也没有可选中通道的交互，要做需先给 selection 加通道（`核心`），暂由检查器自己的 CH1 默认值承担。定义没有给名字的设置以等宽路径作名称；空槽（`NULL`、`NONE`）显示“无”，空枚举值显示“—”；测量槽 `measure.pN.*` 合成一行。分组只靠路径与已有的摘要字段，不改定义格式；是否上面板的逐项标记要等有需要时再做（格式变更）。
- **底部面板**：通信、事件、问题、时间线、运行记录；可折叠、可拖动高度。
- 布局（面板宽度、分屏、展开状态）按测试台保存在浏览器本地。
- 最小窗口宽度 1280 px；面向桌面使用，不做移动端布局。

## 4. 视觉语言

### 4.1 主题

- 深色与浅色两套主题，默认跟随系统；测量类屏幕（波形、频谱）在两种主题下都使用深色绘图区，与仪表习惯一致。
- 中性色为主，主色只用于主要操作与选中；功能色只表达状态。

### 4.2 颜色

| 用途 | 规则 |
| --- | --- |
| 通道颜色 | CH1 黄、CH2 青、CH3 品红、CH4 蓝（与主流示波器一致）；同一通道在卡片、迹线、连线、图例中颜色相同 |
| 端口介质 | 电压信号、参考时钟、触发分别用不同颜色与形状，连线继承端口颜色 |
| 状态 | 正常（绿）、警告（琥珀）、错误/过载/跳闸（红）、未知/断开（灰）；**始终同时显示文字或图标** |
| 仿真专属信息 | 真实值、隐藏状态、保真度标注使用独立的紫色系，与仪表本身的信息区分 |

### 4.3 字体与数值

- 中文：思源黑体（Noto Sans SC）；西文：Inter；数值与通信记录：等宽字体（JetBrains Mono），数字等宽，读数跳动时不抖动。
- 数值：工程单位与 SI 前缀（mV、µA、kHz）；有效位数与仪表分辨率一致；数值右对齐、小数点对齐；单位字号略小、颜色略淡。
- 万用表主读数按「量程 × 位数」显示（#1256）：前缀跟随量程而不是读数大小（100 mV 档的 20 nV 显示 `+000.0000 mV`，不是 `20.00000 nV`），整数位补零到量程的宽度，符号总写出；最细一位是量程 × 10^-(位数−1)（6½ 位即 1 ppm of range），A/D 在当前 NPLC 下的步长更粗时按它所在的十进位再少显示一位；电压与电流不用 k 前缀（1000 V 档写 `+0999.900 V`）。量程与步长来自读数 `<A/D>.<功能>_range`、`_resolution`（`PanelReadout.range` / `resolution`）。
- 中文排版：正文行高 1.6；中西文之间保留间距；按钮与标签不使用全角标点结尾。

### 4.4 密度

专业工具以中高密度为主：基准间距 4 px，控件高度 28–32 px，表格行高 28 px；检查器与通信记录提供“紧凑”选项。

## 5. 核心组件

| 组件 | 要点 |
| --- | --- |
| 仪表节点 | 标题（实例名 · 型号）、通道摘要、端口（按方向分列左右）、错误队列徽标；由仪表定义自动生成（D1）；示波器通道行带波形缩略图，收到 SCPI 命令时短暂闪烁（D44） |
| DUT 节点 | 标题、参数摘要、端口 |
| 连线 | 继承端口颜色；配件以小标签显示在连线中点（如“10×”）；悬停高亮整个网络并显示当前值；运行时按网络电平着色：有信号时以通道色从源向负载流动，0 V 时为灰色（D44） |
| 读数 | 数值 + 单位 + 状态；可固定到检查器顶部。计数器、万用表这类单读数屏幕按仪表前面板只放主读数与状态，屏幕下方留空，不为填满而编造内容（#316：读数历史/趋势要等有真实需求、并能说清它与仪表的统计功能如何区分时再立项） |
| 波形屏幕 | Canvas 绘制；网格与刻度；多通道叠加；缩放、平移；服务端按像素抽取（architecture.md 8.3）。下方是**测量表**：每个显示的通道一行幅值（顶值减底值：方波的设定幅度，不含噪声峰，#1220）、Vpp、频率、周期、均值、RMS，由服务端用该型号自己的自动测量规则（门限、顶/底、交叉电平）在屏幕上的那份记录上计算，停止后与脚本的 `:MEASure:*?` 读数相同，测不出时显示 —。**光标**按钮打开两条时间光标（距左边的格数）与两条电压光标（距中心的格数，按所选通道的 V/div），读出 Δt、1/Δt、ΔV。光标像真机一样在屏幕上直接拖动（拖竖线改时间、拖横线改电压），读数画在屏幕右上角；下方的滑块是同一组光标的键盘操作途径（#356）。光标只在界面上，不发送命令。顶部状态与画面来源一致：运行时写“实时画面”（刷新的画面不是采集），停止或单次后写“采集次数 n”（#280）。**数学函数**：打开显示的函数（`:FUNCtion<f>:DISPlay ON`）由服务端用屏幕上的那份记录算出（不另行采集），时域函数（ADD、DIFF…）以函数色叠加在通道上，变换（FFT 幅度/相位、PSD）在波形下方的频谱区单独画，标出 F<f>、算子、每格刻度、频率范围与频点间隔；频率范围随函数的 `FFT:STARt/STOP` 设定（#1219）。TUI 示波器屏幕同样画函数（tui-screens.md 6.1） |
| 频谱屏幕 | 迹线、标记、参考电平线、RBW/VBW 显示 |
| 通信记录 | 虚拟列表；列：时间、仪表、方向、命令/响应、字节数、耗时；过滤、搜索；二进制块以摘要显示，可展开十六进制 |
| 诊断项 | 级别图标、错误码、说明、位置链接、建议操作 |
| 时钟控制 | 运行/暂停/单步/倍速；步进时钟模式下显示“推进”按钮与步长 |
| 危险确认 | 命令名、目标仪表、影响说明；需显式确认 |

## 6. 交互规范

- **选中联动**：资源栏、画布、检查器、通信记录、时间线之间选中同一对象时互相定位。
- **命令面板**（⌘K / Ctrl+K）：所有操作可搜索执行；常用操作有快捷键并在菜单中标出。
- **编辑**：撤销/重做；自动保存草稿；显式保存为版本；外部修改（Agent、Git）时提示并显示差异。
- **添加的位置**（#1258）：从仪表库或元件库点“添加”（不是拖放）时，新节点放在视图中央；那里与已有节点（含 40 px 间距）相交时，放到离中央最近的不相交的空位，视图随之移到新节点。拖放的节点放在松手处。
- **反馈**：操作 100 ms 内有视觉反馈；超过 1 秒显示进度；可取消的长操作提供取消按钮。
- **空状态**：说明这里会显示什么，并给出下一步操作（如“从脚本生成测试台”）。
- **运行状态**：顶栏的“运行中”带上时钟的实际状态：命令驱动时钟下为“等待命令”或“执行命令”，墙钟下为“时钟走动”；悬停说明画面为什么不变以及怎么让它动起来（D44）。悬停在虚拟时间上列出最近几次推进的时长与原因（#1260）：某台仪表某条命令的执行时间（同一原因连续出现合并为“×N”）、空闲（`run.idle: wall` 时两次操作之间的真实时间，在下一次操作时一次计入，D47）、手动推进、脚本的 `time.sleep`、客户端等待；事件栏的 `advance` 行写同样的原因。命令驱动时钟在 `wall` 档下“等待命令”的说明也写明空闲时间会在下一次操作时计入。动效遵循 `prefers-reduced-motion`。
- **仪表屏幕的动效模仿仪表本身**（`web/src/lib/motion.ts`）：示波器运行时保留前 3 次采集逐渐变淡（余辉），新采集从左往右画入；频谱仪的新扫描在扫频线后重绘、线前仍是上一次扫描，速度随扫描时间（250–1200 ms）。减少动态效果时一次画完，e2e 截图以此模式运行。首页展示的仪表画面必须来自真实运行（D65），首页动效只用产品里真实存在的行为。
- **断开与重连**：与引擎断开时顶栏明确提示，界面进入只读，自动重连后恢复。
- **文案**：遵循 [glossary.md](glossary.md)；错误提示按“发生了什么 → 在哪里 → 怎么处理”。
- **数值调大调小**（#738）：数字设置不必每次输入。输入框右侧悬停或聚焦时出现一对加、减按钮；聚焦后 `↑`/`↓` 步进，`Shift` 加大十倍（梯度则一次一个十倍程）；聚焦后滚轮步进（未聚焦时滚轮仍滚动面板）。每一步立即写入，和回车一样走 `configure`。步长来自设置自己：有梯度（`1-2-5`、`1-3` 或列表）就走下一档，整数加减 1，连续量取当前数量级的十分之一（1.5 kHz 一步 100 Hz），到 `min`/`max` 为止，到头的按钮置灰。只读、被自动开关覆盖（显示“自动”）和断开时不可用。计算在 `model.ts` 的 `stepNumber`。
- **自动与手动设置**（#279、#283）：一个手动值有同名的自动开关（`bw.res` 与 `bw.res_auto`、`sweep.time` 与 `sweep.time_auto`、`sense.range` 与 `sense.range_auto`）且开关为开时，存储的手动值不生效：Web 检查器的该项置灰、值显示“自动”并注明“自动时不生效”（聚焦后显示并可编辑存储值）；TUI 的通用视图显示 `AUTO`。生效值只由仪表屏幕给出（频谱仪的 RBW/VBW/SWT 读数），两处不出现互相矛盾的数字。
- **自动与未给的值**（#1257）：设置值等于定义的 `special` 里 AUTO 的数（万用表量程 0 = AUTO），或等于定义的 `unset`（CONFigure 没给的分辨率、示波器还没设的频谱视图中心频率与跨度），画布、检查器、仪表屏幕与输入框都显示“自动”，不显示“0 V”；聚焦后仍可输入数值。
- **单位**（#1257、#1267）：定义的 `unit` 是 SCPI 的单位，写入时用来识别带单位的参数（`2 V`、`1 kHz`），也决定显示用的基本单位；`display_unit` 只改显示，用于 SCPI 不带单位的量（占空比、对称度写成 `%`，它们在命令里是不带单位的数，显示时不加 SI 前缀：`0.001%`）或显示与存储不同的量（幅度存的是 V、显示 `Vpp`）。SDG2042X 的最大输出幅度是电压，给 `unit: V`；占空比、对称度是百分数，给 `display_unit: "%"`；验收页概览的范围也按 `display_unit` 写。定义的 `display_unit` 是单位词时（SDG2042X 的幅度 `Vpp`），数值带前缀写成“500 mVpp”；输入框只接受自己的单位、它存储用的基本单位或不写单位，写了别的单位（`2 Vrms`、`3 dBm`）提示“设置被拒绝”并写明本框接受的单位（#1286），不按本单位读入。
- **枚举选项的名字**（#1257）：每个选项显示“中文名 + 灰色助记符”。名字依次取设置自己的 `option_labels`、共享词表 `web/src/i18n/option-words.json`（先按选项原样，如 `COMMa` 与 `COMMonmode` 分开，再按 SCPI 短格式）、词表里的编号族（`CHAN#` → 通道 3）；`tests/test_option_words.py` 检查每个内置型号的每个选项都有中文名（数值与序列号、型号这类身份值除外），新型号缺名字时失败。Python 的 `word_of` 与 Web 的 `wordOf` 跑同一份用例表 `web/src/i18n/option-words.cases.json`（#1286），两边不会悄悄分叉。
- **编号的多实例设置**（#1257）：按 `each` 展开的设置（`display.bookmark{n}.*` 一百组）在分组里折叠为一块：选编号，只列这一组的设置；少于 4 组的照旧逐行。“在检查器中定位”到其中一项时自动选中它所在的编号。

- **搭建区**（#1201，instrument-authoring.md 第 9 节）：验收页的“编辑结构”分区（不叫“搭建”，以免与测试台顶栏的搭建模式重名，#1222），工作区定义可在组件图上直接编辑。左栏组件库（按类型、名称或说明过滤），拖到画布上即添加；有通道组件时画布上方一条“每通道”区域，放进去的是通道组件（每个通道一份），区外为整机组件；还没有通道组件时，拖动中画布顶部出现“每通道”放置区（#1212）。`refs` 参数画成带参数名的虚线；节点下部列出它跟随的设置，右栏“设置”页指向或展开一项时，跟随它的组件高亮、其余变淡（#1212）。从输出端口拖到输入端口即连线；`port_pattern` 组件（如采集的 `in1…`）多出一个“+ 新端口”。选中组件或连线后 `Delete`/`Backspace` 或右栏的删除按钮删除，删除组件时注明一并删除的连线与面板端口数。右栏：组件的说明、参数（字面值用 `DraftInput`，回车或失焦写入；绑定设置的显示设置名、只读；`refs` 参数为下拉）；没有选中时分三页：面板端口（添加、选择连到的组件端口、删除）、设置（整机与每通道；点开编辑类型、单位、范围、默认、选项、名称；删除时注明还有多少参数与命令引用它）、命令（命令头 · 绑定的设置或操作；点开改命令头、种类、绑定、可写/可查；通道命令的命令头没有 `<ch>` 时给出警告；Agent 写的其他命令只读）。字面值参数旁的链接按钮把它绑定到设置，跟随设置的参数可以“解除绑定”（#1206）。数值参数接受并显示 SI 前缀；表格参数按行编辑；直接绑定与按映射跟随用同一种标签；组件库按家族分组，每项一行说明与端口；右栏可展开为宽栏，设置与命令可搜索、设置写出用到它的组件与命令；命令页可把交给 Agent 的说明复制到剪贴板（#1214）。命令用法三选一（只写 ↓ / 只查 ↑ / 可写可查 ↕）；类型、用法、每通道、映射、说明段落用图标，文字在提示里。每次修改立即保存，工具栏写“已保存 · 第 n 版”；保存中写“保存中…”，失败用“发生了什么 → 怎么处理”的提示且图回到上一次保存的状态；文件在别处被改时提示并重新载入。诊断在工具栏计数，展开列出，指向组件的在节点上加错误标记。节点可拖动，位置存进工作区（定义旁的 `.layout.json`，不进版本历史），“自动排列”按钮清除它们。右栏的名称可改，改名时连线、面板端口、引用与命令一并跟着改。工具栏有撤销/重做（`Ctrl/⌘+Z`、`Ctrl/⌘+Shift+Z`；输入框里仍是输入框自己的撤销）与“试运行”：底部抽屉里是试运行控制台，每次保存后会话按新定义重开，控制台写明（#1207）。内置型号的搭建区只读，给出“复制为我的仪表”。断开连接时只读。
- **组件与设置以名称为主、标识为辅**（#1251）：组件库、编辑结构的节点、内部结构的块与右栏组件详情，主标签都是组件类型的中文名（英文界面为英文名），类型标识（`scope_vertical`）作灰色副标签；右栏先写一句中文说明，类型自己的英文 docstring 收进默认折叠的“详细说明”。名称与说明来自组件类（`label`/`label_en`/`about`/`about_en`，经 `/api/components` 与内部结构 API），每个内置组件都必须有，缺了单测失败，不在界面上回退成类型名。编辑结构“设置”页每行“中文名 + 灰色路径”，搜索两者都命中。设置分组（检查器、验收页“功能与量程”）的标题按路径首段取 `inspector.group.<段>`（带编号的如 `function3` 取 `functionN`），内置型号与验证仪表的每个分组都必须有译名；没有声明面板的型号按“整机 / 通道 n”分组。
- **复制为我的仪表留在测试台**（#1250）：在测试台的验收标签页里复制，标签页换成副本的验收页并停在原来所在的分区，紧接着提示“让 scope 改用副本？”，确认后把测试台文件里这台仪表的 `model` 改成副本（编辑操作 `replace_instrument`，提示里可撤销）。这个型号已有副本（工作区定义 `extends` 它）时按钮改为“打开我的副本”，不再生成第二份。验收标签页的“在独立页面打开”带上 `?from=<会话>`，独立页顶部因此是“返回测试台 <名称>”而不是“返回测试台列表”；`?section=` 指定打开的分区。搭建模式的元件库里工作区定义标“我的”并写出定义名；检查器“型号”下拉以型号为主，厂商（副本为定义名）灰色在后。
- **连线上的读数牌**：带信号的连线在线旁挂一块小牌——该网络的波形缩略图与一个数（稳定电平写 `DC`，会动的写 `RMS`），所以信号经过被测件怎么变（697 mV → 590 mV）不用点开就看得到；一个网络接了多根线时只在第一根上挂。指向或聚焦小牌，就地展开一张卡片：更大的波形与它的时间窗、DC、RMS、峰值（不等原生提示的延迟）。数据就是画布已有的网络电平（`/levels`），不另发请求；0 V 的连线不挂牌。
- **底部记录面板按需出现**：会话打开时面板收成一条标签栏（通信 / 事件 / 问题），高度还给画布与仪表屏幕；第一次有内容可读（一条命令、一个事件、一个问题）时自己展开到 28%，此后大小由用户决定（拖动、右端的收起 / 展开按钮、点标签）。收起时标签栏上写着最近一条通信。
- **告警徽标**：UNCAL、过载等徽标只在条件成立时出现，悬停说明原因（UNCAL：扫描时间短于当前 RBW/VBW 所需时间）；不以灰色常驻。

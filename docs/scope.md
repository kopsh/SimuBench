# 功能范围与先后

状态：草案，待讨论

## 第一个完整闭环

> 一位工程师，拿着自己的 Python + PyVISA 定标脚本，连到虚拟的信号源和示波器，在界面上看着它运行，发现了一个本来要到产线上才会暴露的问题。

划分原则：

- **闭环必需**：缺了它，上面这句话就不成立；
- **闭环之后**：闭环跑通后最先扩展的能力；
- **以后再说**：有价值，但不影响验证产品是否成立。

## 功能清单

### 1. 引擎核心

| 功能 | 分类 |
| --- | --- |
| 加载测试台文件（仪表、DUT、连线） | 闭环必需 |
| Bench 编辑与校验操作（界面与 MCP 共用） | 闭环必需 |
| 仪表模型自我描述（端口、支持的命令），供 MCP 查询 | 闭环必需 |
| 虚拟时钟，所有状态变化经由统一入口推进 | 闭环必需 |
| 模块化仪表运行时（信号在模块间流动并计算） | 闭环必需 |
| 信号表示：波形（示波器需要）与直流值 | 闭环必需 |
| 连线与阻抗求解（如 50 Ω 源接 1 MΩ 输入） | 闭环必需 |
| 随机种子，结果可复现 | 闭环必需 |
| 运行记录（命令、状态变化、测量结果） | 闭环必需 |
| 虚拟时间加速 | 闭环之后 |
| 频谱等其他信号表示 | 以后再说 |
| 瞬态电路耦合 | 以后再说 |

### 2. 仪表模型

| 功能 | 分类 |
| --- | --- |
| 信号源模型（UTG9604T 类）：定标脚本用到的 SCPI 命令 | 闭环必需 |

| IEEE 488.2 基础：`*IDN?`、`*RST`、`*OPC?`、错误队列 | 闭环必需 |
| 被定标仪表的个体误差与定标系数存储（系数写入后影响后续输出/读数） | 闭环必需 |
| 完整状态系统（状态寄存器、SRQ） | 闭环之后 |
| 更多仪表类别：万用表、电源、电子负载、频谱仪、校准源等 | 以后再说 |

## 闭环需要先确定的一件事

闭环中**谁是被定标的仪表**（信号源还是示波器），决定了哪一个模型需要个体误差与定标系数，以及真值判定检查什么。

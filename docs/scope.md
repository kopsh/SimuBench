# 功能范围与先后

状态：草案，待讨论

## 第一个完整闭环

> 一位工程师，拿着自己的 Python + PyVISA 脚本，连到虚拟的锁相放大器测试台，在界面上看着它运行，发现了一个本来要到真机上才会暴露的问题（例如等待时间不够、驱动导致输入过载）。

开发验证场景见 [validation-lockin.md](validation-lockin.md)、[validation-scope.md](validation-scope.md)、[validation-rfgen.md](validation-rfgen.md) 与 [validation-specan.md](validation-specan.md)。定标场景由产品负责人验收。

划分原则：

- **闭环必需**：缺了它，上面这句话就不成立；
- **闭环之后**：闭环跑通后最先扩展的能力；
- **以后再说**：有价值，但不影响验证产品是否成立。

## 功能清单

### 1. 引擎核心

| 功能 | 分类 |
| --- | --- |
| 加载测试台文件（仪表、DUT、连线） | 闭环必需 |
| Bench 编辑与校验操作（界面与 MCP 共用） | 闭环必需 |
| 仪表模型自我描述（端口、支持的命令），供 MCP 查询 | 闭环必需 |
| 虚拟时钟，所有状态变化经由统一入口推进 | 闭环必需 |
| 模块化仪表运行时（信号在模块间流动并计算） | 闭环必需 |
| 信号表示：网络上传递信号描述，由读取的仪表按需求值 | 闭环必需 |
| 求值方式：谱线（解析式 + 任意波数值计算）、逐点采样、直流值 | 闭环必需 |
| Bench 校验：多驱动源、不支持的串联等错误的明确诊断 | 闭环必需 |
| 连线与阻抗求解（如 50 Ω 源接 1 MΩ 输入） | 闭环必需 |
| 随机种子，结果可复现 | 闭环必需 |
| 运行记录（命令、状态变化、测量结果） | 闭环必需 |
| 虚拟时间加速 | 闭环之后 |
| 频谱等其他信号表示 | 以后再说 |
| 瞬态电路耦合 | 以后再说 |

### 2. 仪表模型

| 功能 | 分类 |
| --- | --- |

| 函数/任意波形信号源模型：正弦、方波、任意波，用于外部参考与输入信号 | 闭环必需 |
| 万用表模型（RC 低通测试台上的旁路测量） | 闭环必需 |
| 示波器模型：触发、采样、量化、IEEE 488.2 波形块与前导信息、耦合、带宽 | 闭环必需 |
| 单位增益缓冲器 | 闭环必需 |
| 射频信号源模型：载波、电平、AM/FM/PM、列表与步进扫描、时基与 REF_OUT | 闭环必需 |
| 频谱分析仪模型：中心/跨度、RBW/VBW/扫描时间/衰减耦合、参考电平与过载、标记与峰值搜索、计数器、外部参考锁定 | 闭环必需 |
| 频谱分析仪模型：接收机噪声底、四种检波器、三种迹线模式、按虚拟时间扫描 | 闭环必需 |
| 频谱分析仪模型：FFT 路径（任意波、PRBS、削波）与能力上限 | 闭环必需 |
| 用户自定义仪表定义（如 PRBS 信号源），从 Bench 旁的目录加载 | 闭环必需 |
| 隐藏状态：Bench 可设置、命令读不到、只能通过测量发现（如时基偏差、噪声密度） | 闭环必需 |
| 参考/时基连线：时基误差沿 REF_OUT → REF_IN 传递 | 闭环必需 |
| DUT：RC 低通（两个场景共用） | 闭环必需 |
| 连线属性：探头衰减比、负载电阻与电容 | 闭环必需 |
| 真实型号模型（如 Keysight InfiniiVision 3000 X） | 闭环之后 |
| 探头电容、线缆长度的瞬态效应 | 以后再说 |
| IEEE 488.2 基础：`*IDN?`、`*RST`、`*OPC?`、错误队列 | 闭环必需 |
| 多通道：通道定义与每通道参数、通道端口、命令中的通道序号映射 | 闭环必需 |
| 多通道：共享组件（时基、触发、存储深度） | 闭环必需 |
| 多通道：共享资源约束（如通道数与采样率） | 闭环之后 |
| 多通道：数学通道、通道组合、通道间相位同步 | 闭环之后 |
| 多通道：通道间时延与串扰 | 以后再说（定标场景需要时提前） |
| 被定标仪表的个体误差与定标系数存储（系数写入后影响后续输出/读数） | 闭环之后（定标场景） |
| 信号源（UTG9604T 类）与示波器（T3DSO2000 类）模型 | 闭环之后（定标场景） |
| 完整状态系统（状态寄存器、SRQ） | 闭环之后 |
| 更多仪表类别：万用表、电源、电子负载、频谱仪、校准源等 | 以后再说 |

| MCP：查看 Bench、收发 SCPI、运行脚本并返回判定 | 闭环必需 |
| MCP：真实值可见性开关（调试/验证模式） | 闭环必需 |
| MCP：用自然语言描述创建与编辑 Bench | 闭环之后 |
| MCP：修改参数、注入故障、控制虚拟时钟 | 闭环之后 |

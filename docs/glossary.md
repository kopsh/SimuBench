# 术语表

状态：生效。界面以中文为主、英文为辅（D23）；界面文案、文档与代码注释中的术语以本表为准。

| 中文（界面） | English | 说明 |
| --- | --- | --- |
| 测试台 | Bench | 核心对象：仪表、DUT、连线与启动设置的组合（D8） |
| 测试台定义 | Bench definition | 可保存、版本管理的测试台文件 |
| 会话 | Session | 由测试台定义打开的可用测试台；打开即可用，没有单独的“运行”步骤（#31） |
| 记录 | Record | 从打开（或重置）后的第一条命令或操作起，记录命令、状态变化、事件与结果（#31） |
| 仪表 | Instrument | 封装好的组件组合，带命令层 |
| 仪表定义 | Instrument definition | 描述一种仪表的声明式文件 |
| 仪表模板 | Instrument template | 用数据手册语言填写的仪表类别模板（D3） |
| DUT | DUT | 被测或被定标的对象；不翻译，界面中文与英文均写作 DUT |
| 组件 | Component | 基本构件：端口、参数、隐藏状态、动态状态、行为 |
| 端口 | Port | 组件或仪表的连接点 |
| 连线 | Wire | 连接两个端口 |
| 网络 | Net | 相互连通的端口集合 |
| 配件 | Accessory | 连线上的探头、线缆、衰减器等 |
| 通道 | Channel | 仪表内部重复的一组组件（D15） |
| 隐藏状态 | Hidden state | 测试台可设置、命令读不到、只能通过测量发现的状态 |
| 个体偏差 | Individual deviation | 一台仪表或元件相对型号标称值的偏差：命令读不到，只能通过测量发现；可由测试台写死，或按定义的指标范围由测试台种子抽取（D3 第 2 层，#34）。界面不再用“隐藏参数”的说法 |
| 真实值 | True value | 隐藏状态等仿真已知的真值（D9） |
| 虚拟探针 | Virtual probe | 不影响电路的信号观察（D16） |
| 虚拟时间 | Virtual time | 仿真中的时间（D12） |
| 命令驱动时钟 / 墙钟 / 步进时钟 | Command-driven / Wall / Stepped clock | 三种时钟模式（D12） |
| 注入故障 | Inject fault | 人为制造通信或仪表故障 |
| 保真度 | Fidelity | 结果的精确程度标注（精确、近似、超出上限、未建模） |
| 能力上限 | Model limit | 模型能表达的范围；超出时报错并标注 |
| 校验 | Validate | 检查测试台或仪表定义；结果为诊断 |
| 诊断 | Diagnostic | 校验结果：错误或警告，带位置与修改建议 |
| 定标 | Calibration (adjustment) | 产线上写入定标系数的过程 |
| 定标系数 | Calibration constants | 写入仪表、修正读数的系数 |
| 调整前 / 调整后 | As-found / As-left | 定标前后的测量结果 |

## 文案约定

- 数值与单位之间不加空格的写法只用于界面紧凑区域（如卡片读数 `5.000V`）；正文与提示中加空格（`5.000 V`）。待设计体系确定后统一。
- 品牌名 SimuBench、SCPI、PyVISA、MCP 等专有名词不翻译。
- 错误提示的结构：发生了什么 → 在哪里 → 怎么处理。

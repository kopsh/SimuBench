# SimuBench 产品概述

SimuBench 是面向研发、测试与校准场景的虚拟仪器仿真平台，旨在将传统依赖真实仪器、硬件接线和实体实验室的测试环境，转化为可构建、可运行、可复现、可共享的软件化测试系统。SimuBench 是纯软件产品，不依赖任何专用硬件。

## 虚拟测试台

平台以虚拟测试台（Bench）为核心，用户可以在可视化画布中组合信号源、示波器、万用表、电源、电子负载、频谱分析仪及其他测试设备，通过仪表端口、连接线、配件和被测对象（DUT）构建完整的测试环境。

每台仪表不仅能够响应自动化测试程序的控制，还可以通过内部功能器件的组合形成信号生成、传输、采集与测量行为，使测试结果能够反映仪表配置、输入信号和系统状态之间的关系，而不只是返回预设的模拟数据。

## 兼容现有测试程序

SimuBench 兼容仪器自动化测试的使用方式，让现有测试程序能够在虚拟环境中进行开发、调试和验证，减少对真实仪器与实验室资源的依赖。用户可以保存、复制和复用测试台，观察仪表状态与信号变化，分析运行记录，并针对特定场景调整仪表行为和故障条件。

## 适用场景

平台支持从单台仪表到多仪表协同的测试环境，服务于以下场景：

- 测试程序开发
- 设备驱动验证
- 自动化流程调试
- 测试方案评估
- 教学培训
- 持续集成

通过共享、版本管理和协作能力，团队可以复用测试资产、统一测试环境，并在不同阶段重现和排查问题。

## 目标与边界

SimuBench 的目标不是取代所有真实仪器，也不是无条件复刻所有物理现象，而是建立一个能力边界清晰、行为可信、可扩展的虚拟仪器生态，让仪器软件、测试程序与测试环境能够在硬件之外独立开发和验证，推动测试研发从依赖实体设备走向软件化、标准化与规模化。
